# ТРИ СТАДИИ

Мемная браузерная мини-игра: дружеский шарж на одну компанию. Сатира, а не пропаганда —
пьяные решения здесь всегда ведут к комичному провалу.

Родион «Квадратный» сидит в баре и сам решает, сколько пить. От того, где он нажмёт
**«ХВАТИТ, ПОШЁЛ»**, зависит, какая из трёх стадий вечера его ждёт:

| Шкала | Стадия |
|---|---|
| 0 | трезвый пошёл домой (скучно, но ачивка) |
| 1–33 | 🛴 Самокат — эндлесс-раннер с пьяным дрифтом |
| 34–66 | 🎣 Рыбалка на озере Круглом — заброс, клёв, вываживание |
| 67–99 | 💬 Петровна — новелла, где выпитое подменяет твои реплики бредом |
| 100+ | отключка прямо в баре |

За забег играется ровно одна мини-игра. Реиграбельность — в галерее из 8 концовок и ачивках.

## Стек

Phaser 3 + TypeScript + Vite. Без лишних зависимостей. Мобильный портрет, тач;
на десктопе — клавиатура-дублёр (стрелки/AD, пробел).

## Запуск

```bash
npm install
npm run dev      # локальная разработка
npm run build    # статика в dist/ с относительными путями (itch.io / GitHub Pages)
npm run preview  # посмотреть прод-сборку
```

## Структура

```
src/
  config/   gameConfig, реестр ассетов, balance.ts — все числа тут
  scenes/   Boot, Menu, Bar, Scooter, Fishing, Petrovna, Ending, Gallery
  systems/  DrunkMeter, MixTracker, SaveManager, AudioManager, DrunkVisualFx
  data/     drinks, dialogue, endings, achievements, strings — все тексты тут
  ui/       Button, Meter, DialogueBox, StageCard, Toast, MuteButton
```

## Графика и звук

Ассеты генерятся позже. Игра полностью играбельна на цветных плейсхолдерах:
отсутствующая картинка рисуется прямоугольником с подписью ключа, отсутствующий
звук молча пропускается. Контракт ассетов — в [ASSETS.md](ASSETS.md); файлы кладутся
в `public/assets/` без правок кода.
